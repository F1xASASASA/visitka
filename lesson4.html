ИС «Мои достижения»

Анализ предметной области по презентации №4.

Объект и цель

Объект — сайт личных выполненных работ студента-разработчика. Цель — показать практические работы и проекты преподавателю и другим посетителям, предоставить понятную навигацию и способ связи.

Контент-анализ

У аналогичных портфолио встречаются главная страница, сведения об авторе, каталог работ, отдельные страницы заданий и контакты. Для учебного сайта ключевыми становятся номера работ, темы и возможность открыть результат за один переход.

Вебометрический анализ

Структура плоская: главная → каталог → работа. Ссылки на GitHub показывают исходный код. Работы должны открываться по относительным адресам и корректно работать на мобильном устройстве.

Сценарии

  1. Преподаватель открывает визитку, выбирает тему и проверяет практическую.
  2. Автор добавляет новый HTML-файл и карточку в каталог.
  3. Посетитель изучает личный проект и переходит к исходному коду.

Сущности

Автор: имя, группа, контакты. Тема: название, номер презентации. Работа: номер, название, файл, тема. Посетитель: просматривает работы. Сообщение: имя, адрес, текст обращения.

Модель навигации

Главная → Практические работы → Задание по теме → Результат. Для возвращения на главную каждая страница содержит ссылку «На визитку».
